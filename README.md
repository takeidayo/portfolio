# 素材の置き場所と名前

ファイル名は **半角英数字・小文字だけ**（日本語・スペースは使わない）。
同じ名前で上書きアップロードすれば、サイトもそのまま差し替わります。

## フォルダは2つだけ

| フォルダ | 入れるもの |
|---|---|
| `thumbs/` | 一覧ページに出る **サムネ画像** |
| `works/` | 詳細ページに出る **作品そのもの**（映像 mp4・静止画） |

## 作品ごとの名前

| 作品 | `thumbs/`（サムネ） | `works/`（作品本体） |
|---|---|---|
| 紋の拍動 | `kamon.jpg` | `kamon.mp4` |
| 少々お待ちください | `wait.jpg` | `wait.mp4` |
| 自主制作アニメ | `anime-1.jpg` `anime-2.jpg` `anime-3.jpg`（一覧で3分割に並ぶ） | `anime-1.mp4` `anime-2.mp4` `anime-3.mp4` |
| 景色を走る | `keshiki.jpg` | `keshiki.mp4` |
| 製氷枡 | `seihyo.jpg` | `seihyo-1.jpg` 〜 `seihyo-4.jpg`（上から順に並ぶ） |
| 滑り道 | `suberi.jpg` | `suberi-1.jpg` 〜 `suberi-4.jpg`（上から順に並ぶ） |

- 名前の決まり：**作品の名前（kamon など）＋ 番号が要るときは `-1` `-2`**
- サムネや mp4 がまだ無い作品は、YouTube のサムネ・埋め込みが代わりに出ます（壊れません）。

## 形式

- 画像：`.jpg`（サムネは 1920×1080 前後、横長 16:9）
- 映像：`.mp4`、1本 25MB 以下
  - HandBrake の「概要」タブで **「Web用に最適化」に必ずチェック**（無いと表示が遅くなる）
  - 縦の映像は「寸法」タブで 解像度制限：なし／アナモフィック：なし（1080×1920 のまま）

## アップロード後

30秒ほど待ってから、ブラウザで **Ctrl + Shift + R**（スーパーリロード）。
